# みんなでまちめし

ともだちと同じ町にお店を出して、お客さんを取り合う3D飲食店経営ゲーム（ブラウザ・three.js）。

- 1〜4人でオンライン（空いたところはコンピューターのお店）
- 1日 = 準備3分（メニュー・値段・内装・店員・宣伝）＋営業7分（自分のキャラで料理・配膳・片づけ）
- 6ジャンル：ラーメン・カフェ・寿司・ハンバーガー・カレー・焼肉
- お店は屋台 → 小さなお店 → 人気店 → 大きなレストラン → 高級店と成長
- みんなが頑張るほど町がにぎわい、外の町から観光客が来る
- 終わりなし。Firebase に保存して、どの端末からでも続きができる（使えないときはブラウザに保存）

## 操作
| キー | 操作 |
|---|---|
| WASD / 矢印 | 歩く |
| Space / E | 近くのものを使う（作る・取る・出す・片づける） |
| クリック・タップ | そこへ歩く／コンロ・料理・席をタップでその場の行動 |
| ホイール・ピンチ / T | ズーム / 町全体を見る |
| Q | 宣伝用カメラ |
| G / M | 画質 / 音 |

通信は PeerJS の P2P（町をつくった人のブラウザが親）。`?local` を付けるとクラウド保存を使わずに起動します。
